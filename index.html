CAFS

Configurable Adaptive FileSystem is a config-first filesystem inspired by the Linux kernel and ZFS, designed with consumer drives in mind.

Proof of concept — pre-alpha CAFS is not production-ready. The on-disk format may still change; do not store data you cannot afford to lose on a CAFS volume. No software can fix a failing drive—CAFS can only try to delay data loss.
Read the project documentation View the source on GitHub README

What works today

The Rust I/O Engine proof of concept builds and passes tests. It provides anchor mount lifecycle and generic block reads and writes. The mkfs_cafs format tool and shared SMART telemetry processor are also present.

What’s planned

The allocator, FUSE request layer, deduplication table, and write-ahead log are not implemented yet. The kernel driver is currently a placeholder.

Configurable by design

Release builds use CAFS-controlled per-interface IPC with guardrails. Custom builds target integrators who want to replace modules or use a standard messaging format.

Build the I/O Engine

The only buildable component is the Linux x86-64 I/O Engine. From the repository root:
